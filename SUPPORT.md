# Support for kombify

| Need | Where |
| --- | --- |
| A question, setup help, sharing your setup | [Questions](https://github.com/kombifyio/roadmap/discussions/categories/q-a) |
| A reproducible bug in a released version | The bug form of the open-source product's own repository; for a hosted product, through the product or by e-mail to [info@kombify.io](mailto:info@kombify.io) |
| An idea or a vote on one | [Ideas](https://github.com/kombifyio/roadmap/discussions/categories/ideas) |
| What is planned and what shipped | [Roadmap](https://github.com/kombifyio/roadmap) and [changelog](https://docs.kombify.io/changelog/overview) |
| A security vulnerability | [kombify.io/security](https://kombify.io/security) or [info@kombify.io](mailto:info@kombify.io), never a public post |
| Your kombify account or a subscription | [kombify.io/support](https://kombify.io/support) or [info@kombify.io](mailto:info@kombify.io) |
| Documentation | [kombify documentation](https://docs.kombify.io) |

Replies may come from an agent, which says so at the end of its reply. The
target for a first response is one business day (a target, not a promise, during the beta); a reply says when it
hands over to a person. Include the version, the release channel (Stable or
Early Access), your environment and the relevant output, with secrets and
personal data removed.

Fixes go to the latest release of each release channel.
