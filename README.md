# kombify ideas and questions

Share an idea, ask a question or follow updates for any kombify product.

| What you need | Where to go |
| --- | --- |
| Propose an idea or upvote an existing one | [Ideas](https://github.com/kombifyio/roadmap/discussions/categories/ideas) |
| Ask a question or get setup help | [Questions](https://github.com/kombifyio/roadmap/discussions/categories/q-a) |
| Read community updates | [Announcements](https://github.com/kombifyio/roadmap/discussions/categories/announcements) |
| Read product release notes | [Changelog](https://docs.kombify.io/changelog/overview) |
| Find guides and references | [Documentation](https://docs.kombify.io) |
| Report a bug, security problem or account issue | [Support routes](SUPPORT.md) |

Search existing discussions before opening one. Upvote an idea that fits your
need and add your use case instead of opening a duplicate. Votes help us
understand demand; they do not promise a feature or a release date. This hub
does not currently publish a list of committed features.

Bugs in open-source products belong in the product's own repository. Account
questions, private feedback and security reports use the private routes in
[SUPPORT.md](SUPPORT.md), rather than a public discussion.

Posts and votes here are public. Remove secrets and personal information
before posting, and read the [privacy notice](PRIVACY.md) and
[Code of Conduct](CODE_OF_CONDUCT.md).
